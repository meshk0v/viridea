# VIRIDEA — интернет-магазин растений с учётом

Интернет-магазин лабораторных микроклонов, адаптированных растений, саженцев и товаров для ухода. В составе:
витрина, личный кабинет покупателя и административная панель со складским, предзаказным и финансовым учётом,
выгрузками в Excel/Google Диск и REST API для подключения CRM.

## Запуск

```bash
npm ci
npm run dev         # http://localhost:5274
npm test            # контрольные сценарии учёта
npm run build       # статическая сборка в dist/
```

Административная панель: `#/admin`.

## Возможности

- **Каталог.** Сорт и товарное предложение разделены. Упаковки микроклонов ×1/×5/×10. Фильтры сохраняются в URL. История цен; в заказе хранится цена на момент оформления.
- **Импорт прайсов лабораторий (XLSX).** Фото привязывается к строке по якорю встроенного рисунка. Цены и количества распознаются из текста. Предпросмотр изменений; повторная загрузка того же файла не создаёт дублей.
- **Поставки и предзаказы.** Подтверждение лаборатории отделено от физической приёмки. Очередь предзаказов FIFO. Персональная ссылка на выбор замены.
- **Склад.** Несколько складов, партии, резервы на 72 часа, карантин, перемещения, списания, инвентаризация. Отрицательный остаток невозможен.
- **Адаптация микроклонов.** Потери и материалы, перенос себестоимости в готовое растение, индивидуальные карточки редких экземпляров.
- **Заказы, оплаты, доставка.** Частичные оплаты, идемпотентные платежи, возвраты, компенсации, несколько посылок на заказ, трек-номера.
- **Финансы.** Выручка по отгрузке, себестоимость, маржинальный доход, юнит-экономика, операционная прибыль, денежный поток.
- **Google Диск.** Очередь выгрузки с повторами, датированные XLSX-снимки.
- **API v1.** Ключи с правами, `Idempotency-Key`, контроль версий заказа, подписанные webhooks. Спецификация: `public/openapi.yaml`.
- **Роли и аудит.** Матрица прав по модулям, журнал всех изменений с автором, причиной и значениями до/после.

## Структура

```
src/engine/   доменная логика: операции, финансы, импорт прайсов, выгрузки, API, контрольные сценарии
src/shop/     витрина и личный кабинет
src/admin/    административная панель
src/ui/       общие компоненты и иллюстрации
scripts/      тесты и генерация примеров прайсов
```
